Science Class 4
13 chapters; 3 quizzes per chapter; 10 questions per quiz; 390 total questions.

Format: question, optionA, optionB, optionC (where present), correctAnswer. correctAnswer contains the full answer text. Source wording and marked answers are preserved; green-highlighted answers in Classes 1 and 2 are read from document formatting.

Each Chapter-XX folder contains data.js. Select localStorage activityNumber 1, 2 or 3 before importing.

Chapter 10, Quiz 1, Questions 5 and 6 have four options in the source. The fourth options are preserved as optionD. A renderer that only reads optionA, optionB and optionC will not show these fourth options. Both marked correct answers are optionC, so they remain available in a three-option renderer.
